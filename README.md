## Описание проекта
Простой API-сервис для вопросов и ответов:
- Создание, получение и удаление вопросов
- Создание, получение и удаление ответов
- Каскадное удаление: при удалении вопроса удаляются все ответы

## Стек технологий
- FastAPI
- PostgreSQL
- SQLAlchemy (ORM)
- Pydantic (валидация)
- Alembic (миграции)
- Docker + docker-compose
